# 水豚噜噜桌面陪伴与任务助手设计方案

版本：v0.4

## 1. 产品定位

本项目只使用一个核心角色：**水豚噜噜**。它不是可切换宠物集合，而是常驻桌面的陪伴入口，帮助用户记录笔记、管理待办，并为未来的答题和学习功能提供自然的交互载体。

核心体验是：用户看到噜噜即可快速记录，完成任务能得到轻量动画反馈，需要学习时可以让噜噜出题、答题和总结。

产品关键词：单一角色、低打扰、快速记录、情绪反馈、学习陪伴、离线优先、Apple 风格。

## 2. 设计系统（Apple Human Interface 风格）

### 2.1 设计哲学

整体界面遵循 Apple Human Interface Guidelines，采用**玻璃态（Glassmorphism）** + **轻量扁平化**的混合风格：

- **玻璃态面板**：半透明白色背景 + `backdrop-filter: saturate(180%) blur(20px)`，营造 iOS/macOS 通知中心般的磨砂玻璃质感
- **浅色背景**：页面背景使用 `#f5f5f7`（Apple 经典灰白），干净明亮
- **SF 风格字体**：`-apple-system, BlinkMacSystemFont, 'SF Pro Display', 'PingFang SC'`，抗锯齿渲染
- **微交互**：按钮 `:active` 缩放 0.97x，hover 背景渐变，过渡动画 0.15s ease
- **大圆角**：卡片 `16px`，按钮 `9999px`（胶囊形），Toggle `13px`

### 2.4 圆角规范

| 标记 | 值 | 用途 |

| sm | `8px` | 输入框、小按钮 |

| xl | `20px` | 大卡片 |
| full | `9999px` | 主按钮、徽章、Toggle |

### 2.5 通用组件

**分段控制器（Segmented Control）**
- 背景：`rgba(0,0,0,0.04)`，内部 2px 间隙
- 激活项：纯白背景 + `shadow-sm`
- 项圆角：`6px`，内边距 `7px 12px`

**Toggle 开关**
- 轨道：`44px × 26px`，圆角 `13px`
- 拇指：`20px × 20px`，白色 + 阴影
- 开启：`#ff9f0a` 背景，拇指偏右
- 关闭：`rgba(0,0,0,0.15)` 背景，拇指偏左
- 过渡：`cubic-bezier(0.2, 0.85, 0.32, 1.2)` 弹性动效

**输入框**
- 背景：`rgba(0,0,0,0.02)`，边框 `rgba(0,0,0,0.12)`
- Focus 态：边框变为 `#ff9f0a`，外发光 `0 0 0 3px rgba(255,159,10,0.15)`

**主按钮**
- 胶囊形，`#ff9f0a` 背景 + 暖橙阴影
- Hover：`#ffb340`
- Disabled：opacity 0.4

**次要按钮**
- 胶囊形，`rgba(0,0,0,0.04)` 背景
- Hover：`rgba(0,0,0,0.08)`

## 3. 功能范围

### 3.1 当前功能

- 桌面透明宠物窗口
- 拖拽移动和位置记忆
- 单击打开任务/笔记面板（玻璃态）
- 双击快速新增内容
- 右键菜单（Apple 风格磨砂玻璃）
- 笔记/任务的新增、完成、删除和日期筛选
- 到点提醒、系统托盘和开机启动
- AI 助手配置：服务商、Base URL、模型、API Key、Temperature、任务上下文
- 分段控制器切换三个功能区：笔记、答题、错题本

### 3.2 未来功能

- AI 根据笔记生成选择题、判断题和简答题
- 基于用户错题生成复习题
- 错题本：按主题查看错题、重新作答和查看解析
- 题目难度、主题和每日题量设置
- 答题结果统计、连续学习天数和知识薄弱点
- 噜噜根据答题结果播放鼓励、思考或庆祝动画

当前答题区域先提供页面框架、返回笔记入口和空状态提示；具体题型、生成方式和统计功能等产品规则由后续需求确定。

## 4. 水豚噜噜角色设计

- 暖棕色圆润身体，低重心，短腿，小耳朵
- 固定绿色围巾或叶子配件，作为识别标志
- 透明背景，所有动作保持相同画布和脚底基线
- 表情简单清晰，缩小到桌面尺寸仍能识别
- 性格安静、可靠、略有幽默感，不连续打扰用户

不要继续维护 cat、dog、robot 等皮肤。角色类型应逐步收敛为 `capybara`，设置页只展示“水豚噜噜”。

## 5. 交互设计

| 操作/事件 | 噜噜反馈 | 业务动作 |
|---|---|---|
| 单击 | 抬头/挥手 | 打开笔记面板 |
| 双击 | 掏出便签 | 快速新增笔记 |
| 右键 | 认真看向菜单 | 新增、设置、隐藏 |
| 拖拽 | 四肢晃动，落地 | 保存宠物位置 |
| 新增笔记 | 点头/记录 | 创建笔记 |
| 完成笔记 | 开心蹦跳 | 标记完成 |
| 到点提醒 | 举牌/敲铃 | 系统通知 |
| 开始答题 | 思考 | 进入答题面板 |
| 答对 | 庆祝 | 记录得分 |
| 答错 | 安慰/提示 | 展示解析并加入复习 |

单击宠物后的功能区采用三个并列的顶部导航入口：笔记、答题、错题本。三个功能层级相同，不把答题设计成笔记的附属功能。答题和错题本当前先提供独立页面框架，后续可以分别扩展题目流程和错题复习流程。

右键菜单不能直接渲染到超出透明宠物窗口的区域。当前方案保持菜单在宠物窗口内部完整显示；若未来菜单内容增加，应改为独立的无边框菜单窗口或使用 Electron 原生 `Menu.popup`。

## 6. 动画系统

动画通过事件触发，不与任务业务代码耦合：

```ts
pet.play('task-complete')
pet.play('quiz-correct')
pet.play('reminder', { priority: 'urgent' })
```

建议动作分类：

- 日常：idle、breathing、blink、yawn、sleep
- 笔记：write、think、task-complete、task-delete
- 提醒：reminder、urgent-reminder、snooze、late
- 答题：quiz-ready、quiz-think、quiz-correct、quiz-wrong、quiz-streak
- 彩蛋：dance、watermelon、hot-spring、rainy-day

动画优先级：urgent > system > interaction > ambient。日常动画可以被业务反馈打断，业务反馈结束后回到 idle。

设置页只保留当前已经接入的选项：宠物隐藏/显示、窗口置顶、任务提醒、提醒声音、AI 配置和开机启动。动画速度、宠物大小、日常动画开关等尚未接入实际播放控制的选项不应出现在设置中。

## 7. AI 与答题设计

AI 服务采用 OpenAI Chat Completions 兼容协议。配置项全部放入设置中心：

- 是否启用 AI
- 服务商
- API Base URL
- 模型名称
- API Key
- Temperature
- 是否发送任务/笔记上下文

AI 不应直接返回文件路径、执行代码或未审核的动画指令。答题功能应使用结构化 JSON：

```json
{
  "type": "single_choice",
  "question": "问题文本",
  "options": ["A", "B", "C", "D"],
  "answer": 1,
  "explanation": "解析文本",
  "sourceNoteId": "note-id"
}
```

答题流程：选择笔记/主题 → AI 生成题目 → 用户作答 → 展示解析 → 保存结果 → 生成复习计划。

## 8. 技术架构

- Electron Main：窗口、托盘、任务/笔记存储、通知、AI 请求
- Preload：通过 `contextBridge` 暴露受控 API
- Renderer：噜噜、笔记面板、设置页、答题页
- lowdb：本地保存笔记、设置、答题记录
- SVG/CSS：基础循环动画
- Lottie/WebP：复杂动作和彩蛋

设置变更必须通过 `settings:get` / `settings:set` 持久化。宠物显示状态使用 `petVisible`：隐藏后通过托盘“显示宠物”恢复。

## 9. 开发优先级

### M1：角色和笔记闭环

- 统一水豚噜噜角色
- 完成笔记 CRUD
- 完成新增、完成、提醒动画
- 设置中的隐藏/显示宠物

### M2：稳定动画系统

- 动画注册表
- 优先级、队列、冷却和回 idle
- 右键菜单独立窗口化

### M3：AI 答题

- 笔记转题目
- 答题面板和结果记录
- 错题复习

### M4：陪伴成长

- 每日学习统计
- 连续答题奖励
- 主题动画包和节日彩蛋

## 10. 验收标准

- 应用中只有水豚噜噜一个宠物角色
- 隐藏后宠物窗口消失，托盘可恢复显示
- 右键菜单不被窗口边界裁切
- 笔记、提醒、AI 设置均可持久化
- AI 失败时不影响笔记和答题记录
- 新增动画只需注册动画 ID，不需修改业务流程

## 11. 三个并列功能区

单击宠物后，功能区提供三个同级入口：笔记、答题、错题本。笔记负责记录，答题负责练习，错题本负责复习。三个页面使用统一的**分段控制器**（Segmented Control）导航、**玻璃态白色背景**和**圆角卡片**视觉，所有页面共享同一套 Apple 风格设计系统。答题页和错题本页先提供空状态与返回入口，后续再接入具体题型、题目生成和错题数据。
